## 常見失分（跨年份）

1. **Time mismanagement**：Section 2(e) Method Statement 經常最後先做，10 分易攞但常失。
2. **唔答題目 set**：改 brief、忽略 crane / thermal / site access 等關鍵約束。
3. **Standard answers**：抄 preparation course 文字，同題目無關就失分。
4. **Two schemes 唔 distinct**：只改 pin 做 portal，grid 一樣。
5. **Stability 唔做**：lateral system 唔畫、唔計。
6. **Form and size 唔完整**：只計 moment，唔做 shear / deflection / fire / robustness。
7. **Method statement 空泛**：要講 temporary stability、partial structure、誰負責臨時支撐。
