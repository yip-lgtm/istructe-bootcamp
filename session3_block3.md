### Scheme 1: RC Post-Tensioned Flat Slab

**Key Features:**
- 300mm PT flat slab + drop panels (150mm)
- 600×600mm RC perimeter columns
- 500mm RC core walls (A + B)
- 10.5m × 4.0m typical bay
- Column-free courtroom (atrium 15m × 15m)
- No bracing to north (glazed facade)
- All lateral via RC cores

**Load Path:**
```
DL + LL → PT flat slab → perimeter beam → column → RC core wall → bored pile foundation
```

**Sustainability:**
- C40/50 + 20% GGBS → embodied carbon ~250 kgCO₂/m³
- Thermal mass reduces operational carbon ~15%
- Bored piles minimize site disturbance (circular economy)

### Scheme 2: Steel Composite Frame

**Key Features:**
- Steel UB sections (typical 457×152)
- Composite metal deck (130mm)
- 305×305×223 kg/m UBP socketed H-piles
- Steel braced cores (west/east)
- 90%+ recycled steel content
- Fast construction (prefabricated)

**Load Path:**
```
DL + LL → composite slab → steel beam → column → steel core/bracing → H-pile foundation
```

**Sustainability:**
- >90% recycled steel → embodied carbon ~180 kgCO₂/m³
- Prefabricated → reduced construction waste
- Steel recyclable at end of life (circular economy)
