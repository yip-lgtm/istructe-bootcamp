# iStructE CM Exam 15-Month Bootcamp

**StructClaw Mentor 專屬版**

## Overview
15 months ≈ 195 intensive sessions.

### Phase 1: Foundation Mastery (Month 1–5)
Thorough mastery of **GUIDEBOOK + Mastery Vol 1** (no past papers yet).

- 3 immersive sessions per week
- Each session focuses on 1–2 sections
- Mandatory: hand-drawn sketches + assumptions + carbon calculation
- Target: every section at 9.5+/10

### Phase 2: Application (Month 6–11)
Full past papers every 10–14 days (latest official IStructE resources).

### Phase 3: Distinction Push (Month 12–15)
Timed 7-hour mocks + weakness targeting.
